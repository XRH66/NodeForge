# v0.1.0 节点支持范围

本页依据 [v0.1.0 节点目录](../Docs/Versions/v0.1.0/Catalog.json)，适用于 Windows 64 位和官方 UE 5.3.2。精确的类名、属性和引脚以目录为准。

## 数量

| 类型 | 数量 | 含义 |
| --- | --- | --- |
| 材质 | 71 种节点类 | 每项对应一种 MaterialExpression 类 |
| Actor 蓝图 | 327 个签名、8 种节点类 | 不同函数、变量类型和节点配置分别列出 |
| 普通材质实例 | 单独的资产类型 | 使用父材质参数，不计入图节点数量 |

327 个蓝图签名包括 299 个函数调用、2 个事件、7 个 Sequence 配置、1 个 Branch、2 个整数 Switch 配置、2 个 Name Switch 配置，以及 7 种变量读取和 7 种变量写入。

目录条目当前标为 `experimental`。节点可以按列出的配置使用，但没有覆盖全部组合、参数及运行效果。

## 材质

支持颜色和数值参数、常用数学运算、插值、向量分量、纹理采样、纹理对象、UV、时间、空间位置与法线，以及支持的材质函数调用。

材质限 Surface 域；混合模式、着色模型和输出必须符合目录规则。所有表达式都必须连接到有效的材质输出。最多 256 个节点和 1,024 条连线；错误类型、未知属性、环或孤立节点会被拒绝。

纹理必须是真实存在、允许读取的普通非虚拟 Texture2D。材质函数需要先读取具体函数的参数、引脚和文件哈希；不能从未绑定的空节点推测动态引脚。哈希只检查直接函数文件，不会递归锁定所有嵌套依赖。

PixelNormalWS、CameraVectorWS 等节点受 UE 着色阶段限制。世界空间与切线空间不能混用；目录允许连接后，仍可能需要在实际材质编译中处理限制。

## Actor 蓝图

支持普通 Actor 的单个 EventGraph，事件包括 BeginPlay 和 Tick。可使用目录列出的函数调用、Branch、Sequence、整数 Switch、Name Switch，以及成员变量读写。

成员类型包括 `bool`、`float`、`string`、`vector`、`int`、`name` 和 `rotator`。函数引脚类型应精确匹配，插件不会自动插入类型转换节点。

最多 128 个节点、256 条连线和 64 个成员变量。Sequence 支持 2–8 个输出。自身根组件调用要求其 `self` 直接连接同图 `Actor.K2_GetRootComponent.ReturnValue`；不能换成任意对象或其他组件。

数组、Map、Set、循环、宏、Timeline、委托、接口、自定义父类、多个图、组件增删和任意函数调用目前未支持。

## 材质实例

可以创建普通材质实例并覆写允许的标量、向量和 Texture2D 参数。父材质必须是已保存、无未保存改动的普通 Surface 材质，参数名和类型需要实际读取。当前没有材质实例专用 MCP 操作，也不支持实例整图导出。

## 输入和结果

JSON 最多 65,536 字节、深度最多 32 层；文件大小限制可能先于节点数上限触发。上限只说明输入允许的范围，不代表达到上限的大图都已验证性能。

新资产只能写入 `/Game/NodeForgeTests/`，已有资产不会被覆盖。输入检查通过后仍需生成和编译；保存成功后还需在自己的场景中查看行为或画面。
