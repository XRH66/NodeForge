# 节点布局测试

本目录包含 19 项构图或拒绝用例。这里记录输入与预期，实际结果由每次运行产生的报告决定。运行环境与通用规则见[开发测试说明](../TestPlan.md)。

## 检查内容

- 材质和蓝图的自动布局、部分显式位置、长标题与默认值。
- 反转节点和边数组，按逻辑 ID 比较实际坐标，检查布局是否稳定。
- 坐标非整数、越界或数组长度错误时拒绝。
- 初始、编译后、保存后和独立重开的坐标一致，显式位置精确保留。
- 报告中的 boundsSize 用于检查自动节点矩形；重叠的显式锚点保留，并返回 explicitAnchorOverlapWarnings。

布局尺寸是保守估算，不是 Slate 真实绘制测量。这个用例组不能替代编辑器中对图可读性的观察，也不检查材质画面或打包。

## 文件与运行

- [Cases.json](Cases.json)：构图与拒绝用例。

构图用例由 [RunGraphRegression.py](../../Scripts/RunGraphRegression.py) 的 `--fixtures Tests/GraphLayout` 选择；提供实际节点目录、匹配插件和新的运行名称。包含目录或资源摘要占位符的模板不能直接粘贴生成，固定摘要的拒绝或兼容用例应保留原值。
