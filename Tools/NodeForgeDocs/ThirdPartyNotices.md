# 文档工具第三方声明

Markdown 渲染使用 [Marked](https://github.com/markedjs/marked) 17.0.5（MIT）。原 `lib/marked.esm.js` 以 `Marked.mjs` 文件名保存，许可原文见 [License.md](License.md)。文件来源和 SHA256 见 [DependencyManifest.json](DependencyManifest.json)。

NodeForge 的渲染脚本负责页面布局、导航、搜索索引及文件输出。主题和资源随仓库提供，网页不依赖 CDN。生成网页需要可运行 ES 模块的 Node.js 环境。
