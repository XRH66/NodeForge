# NodeForge v0.1.0

这是 NodeForge 的第一个可用版本，提供 UE 编辑器插件和可选的 AI 接入包。

| 项目 | 支持情况 |
| --- | --- |
| 操作系统 | Windows 64 位 |
| Unreal Engine | 官方 UE 5.3.2 |
| 使用方式 | UE 面板；支持 MCP 的 AI 客户端 |
| AI 运行环境 | 接入包自带，无需单独安装 Python |
| 生成位置 | 工程的 `Content/NodeForgeTests` 目录 |
| 写入方式 | 创建新资产，不覆盖已有资产 |
