# 兼容性与安装检查

NodeForge v0.1.0 是首个可用版本。本页说明如何选择匹配的下载包，以及安装后怎样确认环境。

## 选择匹配的包

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 64 位 |
| 引擎 | 官方 UE 5.3.2 |
| 普通插件 | `NodeForge-0.1.0-UE5.3.2-Windows.zip` |
| AI 接入 | `NodeForge-AI-0.1.0-Windows.zip`，与上面的插件配套 |

两个包都从 [v0.1.0 Release](https://github.com/XRH66/NodeForge/releases/tag/v0.1.0) 下载。AI 接入工具会核对插件文件和引擎版本；版本不符时不会覆盖现有插件。

已经安装普通插件时，可以直接补装 AI 部分。需要手动离线安装时，把同版插件 ZIP 的位置传给安装工具的 `-PluginZip` 参数。具体步骤见 [连接 AI](../User/AiInstallation.md)。

## 安装后确认

1. 在 UE 插件管理器中确认 NodeForge 已启用。
2. 打开 NodeForge 面板，确认当前工程和引擎位置。
3. 使用附带示例生成第一个材质。
4. 使用 AI 时，让客户端读取文档索引并查询工程状态，确认连接到了预期工程。

安装工具返回 `connected` 表示连接和工程状态读取成功；客户端仍需实际加载配置，才能在聊天中调用工具。

## 使用 JSON 时

本版支持 Graph JSON v2 和 v3。请使用同版示例，或者让 AI 读取当前插件导出的节点规则后编写输入。节点名称、参数和引脚以本版目录为准。

输入中的节点目录标识用于防止把不匹配的规则交给插件。遇到不匹配提示时，应重新核对节点与字段，不能只改标识来跳过检查。

## 移动工程或重新配置

工程和插件的位置会写入本机安装配置。移动目录、更换工程或需要重新连接时，先保存并正常关闭原编辑器，再运行安装入口重新检查当前路径。

客户端的其他设置会保留。如果已有不同的同名 `nodeforge` 配置，先确认它的用途；需要同时保留时，为这次安装指定其他 `-ServerName`。

安装记录包含实际写入的位置和后续命令。出现部分安装或错误时，按记录处理已执行步骤，不要把另一个工程的配置直接复制过来。
