# 生成第一个材质

先按 [安装指南](PluginInstallation.md) 启用插件。本教程使用插件 ZIP 附带的示例，无需 AI，也无需下载测试工程。

## 1. 打开 NodeForge

在 UE 的 **窗口（Window）** 菜单中选择 **NodeForge**。首次打开时，确认工程和引擎位置。

## 2. 载入示例

点击 **载入 JSON 文件**，选择：

```text
你的工程/Plugins/NodeForge/Examples/FirstMaterial.json
```

这个示例描述了一个带颜色和粗糙度参数的材质，目标位置是：

```text
Content/NodeForgeTests/Examples/First/MFirst
```

JSON 是节点图的文字描述，其中包含节点类型、参数和连线。此时只需使用示例，之后再按需要修改。

## 3. 检查并生成

1. 点击 **检查输入**，查看是否有错误提示。
2. 检查通过后，点击 **生成新资产**。
3. 等待生成结束，点击 **定位资产** 或 **打开资产**。

打开材质后，你可以查看节点与连线，并继续使用 UE 材质编辑器修改它。

如果结果中显示 `waitingPersistence`，意思是资产已保存，尚未在重新启动编辑器后检查。它不是保存失败的提示。

## 4. 再生成一份

同名资产不会被覆盖。再次使用同一份输入前，点击 **准备新副本**，检查新名称，然后重新检查并生成。

需要让 AI 编写 JSON 时，先在面板中 **导出全部节点规则**，把规则和你的需求一起提供给 AI，再把返回的完整 JSON 载入插件。也可以 [安装 AI 接入](AiInstallation.md)，让客户端直接读取规则和调用插件。

## 遇到问题

| 提示或现象 | 处理方法 |
| --- | --- |
| 目标名称或 requestId 已使用 | 点击“准备新副本”，换用新的名称后重新检查 |
| 节点规则版本不匹配 | 使用本次下载包附带的示例；让 AI 编写时提供当前插件导出的规则 |
| 输入检查失败 | 点击“打开完整报告”，根据错误提示修改 JSON，再检查一次 |
| 找不到示例文件 | 确认安装的是 Release 中的插件 ZIP，示例位于插件的 Examples 文件夹 |
