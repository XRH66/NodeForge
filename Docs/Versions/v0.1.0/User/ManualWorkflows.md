# 手动操作

安装后，从 **窗口（Window）→ NodeForge** 打开面板。第一次使用建议先完成 [生成第一个材质](GettingStarted.md)。以下操作均在这个面板中进行。

## 从 JSON 生成资产

1. 点击 **载入 JSON 文件**，选择一份完整输入；也可以复制 JSON 后点击 **粘贴剪贴板**。
2. 检查目标资产名称和位置。本版生成位置在 `Content/NodeForgeTests` 下。
3. 点击 **检查输入**。有错误时打开完整报告，修改对应字段后重新检查。
4. 点击 **生成新资产**。
5. 查看结果，再点击 **定位资产** 或 **打开资产**。

再次生成同一份输入时，先点击 **准备新副本** 分配新名称。已有资产不会被覆盖。完整输入示例见 [JSON 示例](../Reference/Examples.md)。

## 让 AI 帮忙写 JSON

即使没有安装 AI 接入包，也可以把规则和需求发给 AI，再手动载入它返回的 JSON。

1. 点击 **导出全部节点规则**，然后 **复制读取内容**。
2. 把规则和你要做的效果一起发给 AI，要求它返回完整 JSON。
3. 把返回内容载入插件，检查输入，再生成。

AI 接入包可以让客户端直接查询规则和提交任务，配置步骤见 [连接 AI](AiInstallation.md)。

## 读取材质参数或函数签名

在内容浏览器中只选择一个已保存、没有未保存改动的普通材质或 `MaterialFunction`，点击 **读取选中材质 / 函数**。成功后，点击 **复制读取内容** 获取参数或引脚信息。

资源必须位于当前允许读取的目录。此操作不接受材质实例、函数实例、材质层或多选。若出现 `sourceMemoryUnproven`，请按 [常见问题](Troubleshooting.md) 处理；插件不会为了读取而自动重载或保存原资产。

## 修改已有图，生成新副本

1. 在内容浏览器中选择一个支持的已保存材质或 Actor 蓝图。
2. 点击 **只读导出选中构图**，将图载入输入框。
3. 修改需要改变的参数，点击 **准备新副本**。
4. 点击 **预览新副本差异**，确认改动内容。
5. 检查输入并生成新资产。

原资产保留。操作细节和支持范围见 [编辑新副本](CopyPreview.md)。

## 自动重排上次生成的节点

点击 **按上次成功输入重排新副本**。插件会使用上次成功生成时保存的 JSON，去掉显式节点坐标，重新排列并生成一份新资产。

它使用上次成功输入，不会读取你后来在 UE 中手改的资产，也不会使用另一份尚未生成的当前草稿。布局尺寸为估算值，生成后可以继续手动调整。

## 创建普通材质实例

先准备已保存的普通 Surface 父材质，读取它的实际参数，再按 [材质实例说明](../Reference/MaterialInstance.md) 填写输入、检查和生成。示例中的资源路径需要换成自己工程里的真实资源，参数名必须与父材质一致。

## 操作失败时

打开完整报告，先看本次是否已经保存资产。如果结果仍为 `pending` 或 `unknown`，保留输入和报告，先查清原操作，不要连续点击生成。
