# 修改已有图，生成新副本

你可以导出插件支持的材质或 Actor 蓝图，修改 JSON，查看改动，再生成一份新资产。整个过程保留原资产。

## 开始前

源资产需要已保存、没有未保存改动，并位于允许读取的目录。普通材质必须能用本版节点规则完整描述；Actor 蓝图限 `Content/NodeForgeTests` 下、只有一个 EventGraph 的普通 Actor 蓝图。

未知节点、多图、循环、数组、自定义父类、材质实例和材质函数整图不支持这项操作。遇到不支持的内容，插件会返回具体原因。

如果读取提示 `sourceMemoryUnproven`，说明插件无法确认内存中的图与已保存文件一致。请先看 [常见问题](Troubleshooting.md)，处理后再开始导出。

## 1. 选择并导出原图

在内容浏览器中只选择一个源资产。打开 NodeForge 的 **已有构图与新副本**，点击 **只读导出选中构图**。

成功后，输入框会显示完整 JSON，插件同时记住原图，以便后面比较差异。导出不会生成资产或修改原图。

## 2. 修改需要改变的值

在构图输入框中编辑参数。例如，修改控制 Roughness 的标量参数默认值，或者修改字符串拼接节点的输入文字。

字段名称以当前导出的内容为准。如果某个输入已经接了线，修改它未使用的默认值通常不会改变实际效果。

请直接编辑这份输入。使用 **粘贴剪贴板** 或 **载入 JSON 文件** 替换整份内容后，原图对应关系可能丢失；这时需要重新导出，才能继续比较差异。

## 3. 准备新名称

点击 **准备新副本**。插件会在当前输入中填写新的资产名称和请求编号，图的其他内容保留。

查看新名称是否符合预期。这一步不会生成资产，也不会提前占用名称。想恢复准备前的输入，可以点击 **恢复上次输入**。

## 4. 查看差异

点击 **预览新副本差异**，再打开完整报告。

| 你的改动 | 应查看的内容 |
| --- | --- |
| 修改一个材质参数 | 对应节点属性改变，其他节点与连线符合预期 |
| 修改参与拼接的文字 | 对应输入默认值改变，连接仍正确 |
| 只更换新资产名称 | 没有节点、连线、设置或位置变化 |

目标名称和请求编号不会被算作图内容变化。预览只比较数据，不会编译或生成资产。再次编辑输入后，应重新预览。

如果原资产在导出后被改动，旧比较结果不再可靠。先重新导出，再核对要做的修改。

## 5. 检查并生成

点击 **检查输入**。通过后，点击 **生成新资产**。

生成时仍会检查节点、引用资源、名称和来源是否有效。若发生名称冲突，先确认是否已经生成过，再准备新副本；若结果为 `pending` 或 `unknown`，先查询原操作，不要直接换名重试。

## 6. 打开新资产

生成结束后，查看最近结果。保存成功时可以点击 **定位资产** 或 **打开资产**，继续在 UE 中编辑，并检查实际效果。

`waitingPersistence` 表示资产已保存，尚未在重新启动编辑器后检查。自动检查重开后的内容需要使用原输入和原生成报告，具体操作见 [AI 副本说明](../Ai/CopyPreview.md)。无需为了普通副本操作另建工程。

## 常见问题

**可以直接覆盖原材质吗？** 当前操作只创建新资产，不能原地覆盖。

**为什么预览按钮不可用？** 需要先导出一份支持图，并保留当前输入与原图的对应关系。

**准备和预览通过后，为什么生成还会报错？** 它们不会预留名字，也不会替代编译。生成时仍需检查当前名称、资源和节点是否有效。

**生成成功就代表运行效果正确吗？** 生成会编译并保存资产；材质效果和蓝图运行行为还需要在自己的场景中检查。
