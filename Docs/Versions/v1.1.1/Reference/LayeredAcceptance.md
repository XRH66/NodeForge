# 材质支持范围

v1.1.1 支持清漆、各向异性、切线和 IOR 折射。字段类型、活动条件与 JSON 写法见[材质设置与输入](LayeredMaterials.md)。

- 清漆权重和清漆粗糙度独立于基础层 Roughness。
- `Anisotropy` 使用标量；`Tangent` 使用切线空间 float3，不能直接接世界空间向量。
- IOR 折射要求透明材质和对应的光照模式。UE 5.3 的屏幕空间折射存在边缘和采样限制。
- 贴图取值需要正确的颜色空间和通道；例如清漆粗糙度与 ORM 中的普通粗糙度不能混用。

这些设置已在代表性材质上检查生成、编译、保存、重新读取和导出。外观仍受模型切线、灯光、曝光、贴图及渲染设置影响；不承诺复现其他软件的全部材质表现。
