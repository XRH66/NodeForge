# 已知限制

以下说明适用于 NodeForge v1.1.1。选择节点或规划任务前，可以先核对这里列出的范围。

## 平台与安装

下载包适用于 Windows 64 位和官方 UE 5.3.2，不适用于其他 UE 版本、定制引擎或其他操作系统。

AI 安装工具支持 `mcpServers` JSON 和 Codex TOML 两种客户端配置格式。客户端是否立即加载新配置取决于客户端本身，可能需要刷新工具列表或重启。尚未验证每一种 MCP 客户端及第二台独立 Windows 机器上的完整使用流程。

## 资产与节点

| 项目 | 当前限制 |
| --- | --- |
| 保存位置 | 新资产必须位于 `/Game/NodeForgeTests/`，即工程中的 `Content/NodeForgeTests` |
| 已有资产 | 只能创建新资产，不支持原地覆盖或合并 |
| 材质 | 只支持已列出的 Surface 材质节点与设置 |
| 蓝图 | 普通 Actor、单个 EventGraph；不支持数组、循环、多图、自定义父类或额外组件 |
| 函数和属性 | 仅可使用当前目录列出的函数、参数类型和设置 |
| 材质实例 | 需要已保存的真实父材质和参数；没有专用 MCP 操作或整图导出 |
| 节点重排 | 通过 UE 面板使用；没有独立 MCP 重排工具 |

节点目录中的 `experimental` 表示实验支持。单个节点可用，不代表任意组合、材质效果或蓝图运行行为都已经验证。

## 读取资源与导出图

资源查询目前支持 Texture2D、MaterialFunction 和 Material。查询列表可能分页、截断或缺少部分元数据；未出现在当前页里不代表资源不存在。

资源列在查询结果中，并不表示它一定能用于生成或完整导出。插件还会检查资源类型、路径、保存状态和所需参数。只读查询列表不会加载资源。

源资产必须已保存、没有未保存改动，且插件能够确认加载内容与文件相符。`sourceMemoryUnproven` 表示这一点尚未确认，处理方法见 [常见问题](../User/Troubleshooting.md)。包含未知节点或不支持属性的图会被拒绝导出。

## 生成结果

检查输入和差异预览不会生成资产。保存成功也不包含实际场景中的运行、渲染、性能或打包检查；这些结果需要在自己的工程中确认。

`pending` 或 `unknown` 表示操作尚未有明确结果。应读取原调用和报告，确认有没有保存资产，再决定下一步；不要更换名称反复提交。

## AI 操作

读取文档可以离线进行。操作工程需要正在运行且已连接的 UE 编辑器，并由当前连接独占控制。安装工具只负责一次接入，不自动启动工程；日常正常打开 UE。MCP 不提供任意工程启动或退出操作。多个候选必须明确选择，旧句柄不会改指新会话。

关闭面板或 AI 客户端不会自动取消已提交的 UE 任务。结束本客户端连接时，确认原调用已收尾，再使用 `nodeforge_disconnect` 正常释放租约；下一客户端重新取得句柄，无需关闭 UE。停止工程服务与关闭编辑器是另外的生命周期操作。

## 客户端检测边界

本版已验证 Codex 的实际握手、调用和定向断开。Claude/DeepSeek 只提供图标、选择、实际标准配置和入口框架，明确显示未检测；没有其专有检测、进程探测或自动重连。自定义项同样不凭选择冒称在线。

## 调用容量

业务调用表容量为 128；本版提供主动回收接口，按每 50 次业务调用清理后继续。原报告与原编号仍保留，不自动删除；未解决调用会阻止回收。见[调用回收](../Reference/CallCapacity.md)。
