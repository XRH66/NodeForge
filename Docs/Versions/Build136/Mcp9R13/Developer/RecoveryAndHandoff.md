# 换账号与恢复交接

使用交付包时先读InstallationManifest、准确版本Manifest、Readme、DeveloperArchitecture和SourceMap，核实际安装与权限；交付包不含维护库五文件/台账/原报告。进入完整维护库开发时，再按根1.md→AGENTS.md→ProjectContext.md→ProjectStatus.md→Handoff.md读当前状态和权限，再读准确版本的Readme/DeveloperArchitecture/SourceMap及当前任务计划、最近Review。用户实际授权和当前get_goal分别核实；get_goal=null仅表示当前对话无Goal，不否定项目完成。不得从历史正文恢复旧执行权。新账号须具备本机文件/MCP权限，不能只靠文档取得权限或凭据。

核当前Build/stage/DLL、桥/契约/资料SHA、引擎、Catalog/Operations、根安装/RC1分层；历史PID/SessionPublic/handle只作原证据。没有UE时可以读资料，不猜现场。开发前只定点读取SourceMap中需要的模块和原报告，核真实Goal及7天额度、原生停止限制；不更换模型/速度、不购买/兑换。

中断先保存原call/原CLI/run/输入/收据/可能写入、准确PID和创建身份、unknown/pending、源/草稿/基线关系、当前台账和保护；只查原结果，不重放。确认未提交且原因已解才能一次有限恢复。源码/证据冲突或需扩大范围先停说明。

更新当天日志、ProjectStatus、Handoff、索引和必要Review：完成到哪、实际改文件/验证层、未解决/部分写入、下一具体动作及授权。canAdvance=false不进入下一步；预算收尾不是complete。历史失败/原报告/旧字节保留。当前进度以根状态与真实Goal为准，发布包提供稳定知识，不冻结“现在的PID/额度”。

下一版维护按DeveloperVersionRelease，扩展三类按DeveloperNodeExtension/OperationExtension；陌生AI理解软件知识的验收不要求它自主设计图或开发代码。
