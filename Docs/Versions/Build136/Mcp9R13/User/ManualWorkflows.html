手动任务路线

使用手册9 个章节约 4 分钟

本包对应 NodeForge-Build136-Mcp9R13 / Build136 Repair6。新任务使用当前完整输入与新身份；具体字段见统一资产设置、资源选用和JSON规则。准确验证范围集中在发行说明。

从样例生成新资产

  1. 取得合法样例。材质使用 StaticColor，Actor 蓝图使用 BlueprintConcat。
  2. 使用新资产目标、requestId 和本版目录摘要。
  3. 载入完整输入，点击 检查输入。
  4. 检查通过后点击 生成新资产。
  5. 打开完整报告，按需定位或打开资产。

StaticColor 使用 VectorParameter 和 Multiply 连接到 Material.EmissiveColor。BlueprintConcat 使用明确函数绑定，目标是 Actor 的单 EventGraph。精确字段与连接以样例为准；保存结果不保证材质画面或实际运行已验证。

读取材质或函数信息

前提： 内容浏览器中只选一个已保存、没有未保存改动的普通材质或 MaterialFunction。对象位于 /Engine/ 或批准的测试目录；材质实例、函数实例和层不在此操作范围。

  1. 展开 节点规则与资源查看。
  2. 点击 读取选中材质 / 函数。
  3. 读取成功后点击 复制读取内容。

结果包含真实参数或函数签名，以及源文件 SHA。这个操作不生成资产。读取失败会清空旧的复制缓存，避免误用上一份内容。

源还须具有当前进程的受控保存文件加载证明。已经手动载入却没有证明的对象会显示 sourceMemoryUnproven；插件不会自动重载、保存或编译源。应在新准备的专用编辑器里先通过正式读取，再手动打开源资产。源为 dirty、尚未就绪或蓝图未编译时，先处理原问题再进行新的明确操作。

从已有图准备新副本

前提： 只选择一个已保存、没有未保存改动的普通材质，或测试目录中的普通 Actor 蓝图。

  1. 展开 已有构图与新副本。
  2. 点击 只读导出选中构图。它读取源图，准备短的新身份，并在当前草稿修订仍匹配时载入完整输入与比较基线。导出 API 本身只读；这个载入动作是 UI 的后置提交。晚到结果不能覆盖后来编辑的草稿。
  3. 确认新目标，按需编辑输入。
  4. 点击 预览新副本差异，确认源资产和比较基线仍对应。
  5. 点击 检查输入，再点击 生成新资产。

导出与差异预览不修改源资产。无法完整表达的属性、多图或未知节点会被拒绝；需要明确点击生成才写入新资产。

重排上次生成结果

  1. 确认要重排的是 上次成功输入。
  2. 点击 按上次成功输入重排新副本。
  3. 查看本次派生输入与完整报告；需要独立 Verify 时使用这一份输入和报告。

此按钮会去掉原输入中的显式坐标，分配新身份并生成新资产。它不读取后来手动编辑的资产，也不使用当前无关草稿。旧资产和原输入保留。报告中的尺寸是估算值，不能保证所有屏幕上的布局效果。

使用普通材质实例

  1. 准备已保存、没有未保存改动的普通 Surface 父材质。
  2. 读取实际父材质参数和文件 SHA。
  3. 按材质实例参考填写真实依赖与覆写，再走检查、生成和结果确认。

示例路径不代表本机已有资源，不能虚构父参数。手动实例能力的历史证据保留原版本；实例 MCP 本期没有新实测。

失败后如何处理

先看完整报告，并确认是否已经部分保存。结果未知时，保留原调用、输入和报告，不换名称重复生成。

本版验证到哪一步

正式CLI已读取普通材质参数与函数签名，MCP已导出材质和Actor蓝图并各生成一件副本，两件都通过独立保存重开核验。两处实际按钮点击证据属于Build128，相关按钮和共享业务源码连续到Build130；不声称Build130重新点击了所有类型的按钮。上述两族副本属于有限B/C的原版本证据。本候选另有一件资源引用Masked材质的实际GPU、最小无生成器副本和Win64包后运行证据；不能外推所有旧样例的画面或运行。完整输入在AI样例页。

修改已有图的新副本

按编辑新副本教程，选中受支持的已保存原材质或Actor蓝图，导出到输入区，编辑后点准备新副本、预览差异、检查输入、生成新资产。准备和预览不保存新资产；真正生成才编译保存。本版材质准备/预览/恢复按钮已实际核验，材质与Actor蓝图的新副本正式调用、编译保存和独立重开核验已通过；其它按钮保留各自历史版本依据。详情见本版发行说明。
