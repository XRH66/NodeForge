# 用户手册

NodeForge 把规则范围内的 JSON 构图描述变成可继续编辑的虚幻资产。这份手册介绍插件能力、操作方法和结果判断。

首次解压绑定见[安装说明](Installation.md)，生成后核验和正常结束见[AiPreparation](../Ai/Preparation.md)。

## 第一次使用

- **[插件介绍](Overview.md)**
  了解能生成什么、支持哪些操作，以及当前的使用范围。
- **[开始使用](GettingStarted.md)**
  确认版本、打开面板，完成第一次输入检查和生成。

## 选择操作方式

- **[手动操作](ManualWorkflows.md)**
  在 UE 中载入输入、读取资源、导出已有图或生成新副本。
- **[使用 AI](AiWorkflows.md)**
  配置 MCP 连接，了解需要人工准备什么，以及如何给 AI 下达任务。

## 操作时查阅

- **[界面与按钮](InterfaceGuide.md)**
  查询每个按钮读取什么、何时可用、点击后的效果和下一步。
- **[问题处理](Troubleshooting.md)**
  判断输入失败、名称冲突、按钮禁用和保存后的核验状态。

## 本手册适用范围

本手册对应 NodeForge-Build136-Mcp9R13。开发用插件与已经安装的插件可能是不同版本；阅读手册不会升级根安装或 RC1。

这是本地离线资料，不依赖网络、登录或旧聊天。普通操作可以先看本手册，详细 JSON 和调用参数由 AI 阅读专用资料。
