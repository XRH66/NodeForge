本页对应 NodeForge-Build136-Mcp9R19 / Build136 Repair6，目录摘要由当前正式目录生成。下面是完整当前配方，保留原有限样例的节点、属性和连接语义；它们不是历史导出原payload或已保存来源证明。当前schema、类名及事件/函数绑定已静态核对，目录仍experimental。新任务先确认授权与本次实际目录/目标占用，按AiPreparation使用新的requestId和完整目标，保存实际输入原字节后正式预检；示例身份不预留，也不能把换digest当旧能力升级。

带资源依赖的配方先精确inspect当前已保存、clean资源及实际文件SHA/函数GUID签名。全零assetSha256是明确未取得证明的占位值，结构合法但不可直接预检生成；必须用本次返回的真实值。若资源/参数/端口与配方不匹配就停止，不能修改来源报告或凭文档补造证明。完整材料引用正例见AiResources。

材质以标量/颜色/数学链连接到Unlit活动输出；蓝图把普通纯函数结果交给成员、Branch/Switch、消息或自身根组件消费。节点不因列出就算运行通过；准确pin/default/property以同包节点页和实际Catalog为准。
