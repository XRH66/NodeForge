AI 调用手册3 个章节约 2 分钟

已有资源的准确读取、函数签名、两族完整导出及带来源的新副本，先读显式读取配方。工具帮助也直接导航pageId=AiAssetRead；普通从零构图继续沿QuickStart/TaskRecipes，不把单节点模板当作完整Graph。

从工具描述调用 nodeforge_docs_index，确认 NodeForge-Build136-Mcp9R19、桥 0.3.6 和 Manifest SHA。所有下列资料都有 docs_read 的 pageId；文件链接供本地阅读，不能替代正式入口的版本确认。

发现索引提供版本、能力数量、读者入口和指南导航，最多32768字节，不把整包源码/维护证据清单塞进每次发现结果。完整知识分别通过下列pageId读取；来源与许可见SourcesAndLicenses，源码地图见DeveloperSourceMap，本机完整Manifest保留全部绑定。resultTooLarge表示没有返回完整发现摘要，不把它当正常passed或截断内容。

新资源选用先读AiResources：有界元数据查询、准确inspect、完整2/3引用输入、原正式调用与恢复。列表不建立来源或导出证明。

调用前阅读

  • 调用流程 pageId：AiQuickStart。理解正式工具、草稿修订和调用顺序。
  • 准备工程与身份 pageId：AiPreparation。取得真实会话、批次、目标和独立 Verify 条件。

请求与结果

  • 任务与调用例子 pageId：AiTaskRecipes。沿真实参数完成既有任务。
  • 合法 JSON 样例 pageId：Examples。复用现有合法图结构，另分配实际身份。
  • API 参考 pageId：AiApiReference。查本版输入、返回和分支定义。
  • 结果与恢复 pageId：AiResultsAndRecovery。区分保存、Verify、pending 和 unknown。

支持范围
