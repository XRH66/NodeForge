可重复版本发布配方

原理与开发0 个章节约 7 分钟

维护源在Docs/PluginControl/DocumentationSources（Markdown/Pages/Controls/NodeDocumentation）；真实Catalog/Operations及原EvidenceIndex是机器事实。ReleaseInput明确版次、Build/stage/engine/adapter、基础manifest、原ToolContract、作者元数据、输出、保护来源及渲染器。公开包的产品发布说明为 Docs/Versions/Build136/Mcp9R19/PublicRelease.json；带本机渲染器/工程/证据输入的完整 ReleaseInput 由维护者在内部报告中保存，不随安装包分发。维护时从内部本版输入接续；先对照本包Manifest、发布复核和实际源身份，再复制为下一版输入，不从历史B2路径猜当前版本，也不运行历史P0 Freeze.py。OperationsCandidate来自同一核心定义的静态冻结，发布器不称它是在线describe；每个有产品影响的新候选须核真实宿主返回；旧B3属于其原有限证据，不能当当前describe。目录沿未变Specs复用原真实快照，其原Build身份与历史证据保留。

  1. 先核用户范围、Goal/额度、原保护；普通节点沿核心更新，特殊语义与新业务按各自路线。DLL未变只新资料/桥版次，真实C++变更才新Build/同stage必要验证。
  2. 取得正式Catalog/Operations、准确DLL/源连续性和证据。更新精确NodeDocumentation的用途/前提/限制/片段/来源；新业务先adapter/统一Operation和显式AI政策，再帮助/schema/页例子。文档源不能只是复制旧页换版本号；共同事实一处维护，作者复核新语义。
  3. 复制ReleaseInput到新报告目录，改bundleId/buildId/bridgeVersion、manifest/目录/操作/证据/输出/作者版绑定。更新reviewedCoreBinarySha256证明资料作者核过该核心；新SDK改依赖锁并按影响验证。本机渲染采用已有marked17.0.5，许可/文件SHA见SourcesAndLicenses；nodeExe用实际已配置Node路径，不默认安装。
  4. 发布前先核桥源码的实际VERSION与输入bridgeVersion一致。发布器只静态读取VERSION，不导入/执行桥；不一致时在创建输出前停止。升级维护窗口内先确认没有未结调用和活动旧编辑器，保存旧脚本/契约/Config字节，然后准备真实候选源码版本，再运行已有发布器。已载入0.3.2或后续兼容Application ABI的服务保持原stdio连接；成套发布前暂不调用，避免观察不完整发布。SDK/Python解释器或Application ABI改变才需要一次服务级载入。候选报告中暂存的源码属于待激活字节，不能冒称根目录已经安装。包、契约、配置未成套完成之前不要重新开启旧配置服务；发布失败按完整旧快照恢复后再重连。不得清锁、强杀UE或借版本号跳过保护。

运行已有发布器：

& 'ReplaceWithInstallationRoot/Tools/NodeForgeMcp/Environment/Scripts/python.exe' 'ReplaceWithSourceRoot/Scripts/BuildNodeForgeUsageDocs.py' --release-input 'ReplaceWithNewAbsoluteReleaseInputPath'

发布器要求新输出不存在，frozen和任何已有目录拒绝覆写。候选输出只允许Docs/Versions；显式validationOnly才允许本阶段Reports内演练。节点/操作/控件/必须主题缺解释阻止发布；页与原字段/字节/SHA、精确identity绑定，不固定Build122或工具/节点数量。生成Diff/Coverage/DocumentationIndex/Manifest和User/Index.html；图数据未变不增加tool。 5. 复核参数/真实输入、重复性、差异、每类读者知识、离线渲染/链接与保护。发布器将新包业务验收置为notEstablished，并记录核心/CLI/Operations是否未变，不自动继承基础包的passed。影响Review明确核桥业务/核心/CLI和旧证据后，才可登记复用结论；业务实现变化先写理由再最小正式回归及必要newPID Verify。新帮助/SDK/当前客户端只查受影响元数据。 6. 候选完整性/静态Review通过后，在同一维护窗口完成全局ToolContract、实际脚本与批准Config成套SHA。桥0.3.2及其Application ABI 1接续核已载入、依赖锁未变、旧编辑器与call已终结时，下一次docs_index/tools/list会执行新发布绑定的NodeForgeMcp、Bridge、EditorTransport、RunProcessGuard应用代码，并接续DLL/目录/业务绑定，无需逐版手动开关。载入器先验证批准Config/契约/Manifest和准确源码字节，使用独立模块代次，不改旧模块；任何inflight、unknown、pending、未结磁盘call、存活旧编辑器或外部lease均阻止切换。新handle须显式connect取得；不启动UE、不重放业务。configurationRefresh.applicationCodeReloaded与loadedRuntimeFiles、同PID的serviceRuntime、RuntimeObservations和接续收据用于核实际载入；ProtocolSeen保留首次历史观察，不能只比磁盘SHA。输出schema的bridgeVersion是版本字符串，准确版次仍在批准契约与Manifest中严格绑定；不得固定为旧版本常量导致客户端缓存拒绝新版返回。旧0.3.1及更早进程没有此载入能力，首次安装修复版需要一次实际服务载入；SDK/Python解释器更新或接续核ABI变更仍需服务级载入，全应用重启不默认。实际docs_index/docs_read的bundle/SHA与工具帮助确认，不能只看磁盘。真实客户端及所有必需Review达标才冻结manifest；纯资料SHA按原机制刷新。不能先写“已完成冻结”，再等真实加载结果。 7. 发布最终Review/输入/回退清单、根ProjectStatus/Handoff/日志/索引；全部必需项通过才Goal complete并回读，停止等待下一个有限授权。

同版只有资料纠错可以沿固定Config批准docsManifestSHA做安全刷新，保持全部执行/业务/schema绑定和unknown/lease；frozen原包不能改写，纠错另存修订。代码/DLL/SDK/业务/schema变更不能冒充文档热刷。回退需完整脚本/契约/配置/依赖身份和旧资料，见VersionCompatibilityAndMigration。

若配置在收尾前提前更新，0.3.1仍允许原handle查询已登记原calls.get/report_read，使用原契约和身份并核原代码/报告字节，返回configurationRefreshPending；不允许新的读写业务绕过版本核验。原unknown收束及旧会话关闭之前完整接续保持阻塞。服务关闭时，unknown/pending/未收束CLI或磁盘非终态Calls保留原lease与记录；不能靠关闭服务清理未知工作。SDK适配证据与真实当前客户端加载必须分开登记。

同版资料修订同步全部页、Manifest绑定/HTML、本地资源和搜索，保留当前业务与SDK代码身份。原发布器现在对所有完整NodeForgeGraph代码块核当前GraphRequestSchema，资源依赖占位仍需明确用途和本次实际证明；静态schema通过不能替代native语义、来源或目标占用检查。源码地图区分交付包与维护库材料，节点/事件/业务三类扩展继续沿共同定义。新工具需实际tools/list核元数据；现代协议没有相应旧通知时不声称订阅已支持。

本版离线站点由发布器layoutTheme=hero选择Scripts/RenderNodeForgeDocsHero.mjs，准确设计来自用户已认可的Tools/NodeForgeDocs/HeroPreview/Config.json和Renderer.mjs，版本2.4.1-preview；同时复用其Theme2颜色/搜索资源及原品牌。勿调用写死旧预览目录的PreviewNodeForgeDocsHero.mjs覆盖正式候选。共享职责仍按主题文件分工：Config管分类/导航/品牌，Theme.css管颜色与版式，Theme.js管主题/搜索/复制，Renderer.mjs管框架和资源；正文仍由本版authoring Markdown维护。新增已登记页自动进入导航和搜索，不逐页复制HTML。发布器读取同次LayoutManifest，把主题/品牌来源、全部HTML和本地资源纳入准确SHA；不能只更新页面忽略Assets或沿用旧HTML指纹。仅更新正文时，沿当前主题重渲染候选并批准成套文档SHA；修改已绑定主题源码须按代码变更重新核发布与服务加载。冻结包不得原位重渲染。主题维护源说明在Tools/NodeForgeDocs/Theme/Readme.md；这段配方已包含无记忆维护所需职责和顺序，包外路径只作源码定位。
