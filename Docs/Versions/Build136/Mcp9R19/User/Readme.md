# 用户手册

NodeForge把JSON构图描述变成可继续编辑的UE材质和蓝图。先选择你要怎样使用，再看对应安装步骤。

## 开始使用

- **[普通插件安装](PluginInstallation.md)**：在UE面板手动载入JSON、检查输入、生成新资产。无需MCP依赖。复制文件夹安装正在规划；当前候选的一次绑定步骤也在这页。
- **[AI接入安装](AiInstallation.md)**：在插件基础上配置AI连接。自带环境的一次配置包尚未发布，当前可用方法单独列出。
- **[安装方式对照](Installation.md)**：不确定该选哪种时，从这里开始。

安装后按[开始使用](GettingStarted.md)做第一次输入检查。先了解功能可看[插件介绍](Overview.md)。

## 按任务查阅

- [手动操作](ManualWorkflows.md)：载入输入、读取资源、导出图和生成新副本。
- [使用AI](AiWorkflows.md)：填写客户端、给AI下达任务和查看结果。
- [界面与按钮](InterfaceGuide.md)：按钮用途、可用条件和操作效果。
- [问题处理](Troubleshooting.md)：输入失败、名称冲突、按钮禁用和结果状态。

## 适用版本

本手册对应NodeForge-Build136-Mcp9R19，插件核心为Build136 Repair6。这次资料更新拆分安装步骤，未交付新的安装程序，也不会升级已有插件。

详细JSON和调用参数见[AI调用手册](../Ai/Readme.md)；支持范围、发行记录和回退见[本版说明](../Version/Readme.md)。
