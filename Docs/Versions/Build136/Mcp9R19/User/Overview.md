# 插件介绍与能力

适合把已有的结构化方案落成普通材质、单EventGraph的Actor蓝图，以及依赖已保存父材质的普通材质实例。输入描述节点、属性、默认值、连接和设置；输出是新资产、完整报告和保存收据。生成结果仍可以在UE编辑器继续编辑。当前不会覆盖原资产。

## 支持的资产

| 类型 | 当前能力 |
| --- | --- |
| 普通材质 | 颜色、参数、数学、插值、贴图、UV、空间与法线，以及有限函数调用 |
| Actor 蓝图 | 单 EventGraph；有限事件、函数、成员变量、分支、Sequence、整数与 Name Switch |
| 普通材质实例 | 依赖已保存父材质的真实参数和文件 SHA，支持批准的覆写 |

循环、数组、多图、新父类、额外组件、任意对象和函数不在当前范围。完整数量和精确限制由公共能力参考维护。

## 可以怎样使用

- **在 UE 中手动操作：** 载入、检查、生成、查询规则、读取资源、导出受支持的完整图、比较新副本差异，以及重排上次成功输入。
- **让 AI 通过 MCP 操作：** 草稿、查询、预检、生成、状态、原调用、报告和资料读取。

资源读取和两族完整受控图导出已有正式 MCP 工具，AI 可以读取一个准确资源，并沿原导出创建新副本。源须已保存、干净且通过受控加载证明，未知节点或无法完整表达的图会拒绝。准备新副本与差异预览也有正式 MCP 工具，人工按钮和 AI 使用同一核心；重排仍为手动能力。

## 如何判断结果

目录中的 experimental 表示受控实例可发现、可构造。某个配置与组合的实际验证需要对应报告，不能从节点数量推断。

生成与保存、独立重开、实际运行、材质画面和打包是不同层级。保存后仍等待独立重开时，不能认为实际运行已经成功。

## 新增普通节点怎样用

你可以组合更多原生数学、比较、字符串/名称、向量和旋转函数，以及材质数学表达式；当前精确目录为 71 材质类 / 327 蓝图签名。支持不等于开放全部 UE。先看 [节点选择与支持层次](NodeCoverage.md)，再按任务查询实际引脚。仍可在 UE 人工打开生成资产看效果；本版自动验收的生成/保存/独立重开与实际运行、材质画面分开记录。
