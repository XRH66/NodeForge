普通插件安装

使用手册3 个章节约 2 分钟

只在UE面板载入JSON、检查输入和生成资产，安装普通插件即可。新的普通安装候选是 Build137 Repair5，支持Windows x64、官方UE5.3.2；首次安装不需要Python或MCP环境。

四步安装

  1. 正常关闭要安装的工程，将候选包中的 NodeForge 文件夹复制到工程的 Plugins 目录。没有Plugins就创建它。
  2. 打开工程，在插件列表启用NodeForge。若UE提示重启，正常重启该工程。
  3. 从 Window（窗口）→ NodeForge 打开插件。首次显示准备页，自动识别当前已打开的工程、正在运行的引擎和插件。
  4. 确认信息，点击 确认当前工程并开始使用。配置保存后进入功能页；以后打开此工程会直接进入功能页。

确认成功： 准备页切换为包含“构图输入”“检查输入”等按钮的功能页。关闭并重新打开NodeForge面板，不会再次要求首次确认。

界面使用实际工程和引擎路径，不是占位文本。当前工程和引擎已由你打开UE时选定，不需要再浏览文件或手填路径。更换引擎时，请先用匹配的引擎打开工程；安装页不会把当前进程绑定到另一套引擎。

安装后做什么

可以载入插件 Examples/FirstMaterial.json 做第一次输入检查。要生成自己的资产，请先修改完整目标和requestId，使用新名字；检查本身不生成资产、不预留名称。完整操作见开始使用。

生成仍限于/Game/NodeForgeTests/，只创建新资产。默认读取工程测试内容、引擎基础资源和有限材质函数目录；其它内容不会因安装自动开放。

已有安装或遇到问题

  • 已有外置NodeForge： 不要叠放第二份插件。先按原安装收据撤销旧绑定，原资产保持。首次确认不会覆盖已有或无效配置，也不会清理重复插件。
  • 版本不匹配或资料缺失： 检查完整包与引擎是否匹配；不能只复制DLL或旧版PluginStage。
  • 只是启用了插件： 首次打开NodeForge后还需确认当前工程。

诊断见问题处理。不要分享工程的私有绑定、运行报告或收据；公开分享使用干净原包。

本页介绍新普通安装候选。原Build136 Repair6完整候选的外置步骤保留在原版手册。AI自带环境/一键配置包尚未发布；现有AI安装见AI接入安装，使用其指定的Build136完整包，不将普通包当作MCP环境。
