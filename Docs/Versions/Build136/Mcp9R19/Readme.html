将JSON构图描述转换为可编辑的UE材质和Actor蓝图。支持Windows x64、官方UE5.3.2；具体节点和配置以当前目录为准。

先选一种使用方式

  • 普通插件：在UE面板里载入JSON、检查并生成。无需配置AI；复制文件夹安装正在规划，当前候选仍需一次工程绑定。
  • AI使用：让AI发现节点、读取资源并提交任务。AI运行环境单独准备，自带环境的一次配置包尚未发布。

安装方式对照说明两者区别。安装完成后，从第一次使用开始。

使用时查什么

  • 用户手册：安装、界面、手动操作与问题处理。
  • AI调用手册：合法输入、正式调用与结果恢复。
  • 完整JSON例子：材质、蓝图及需要真实父依赖的实例配方。
  • 功能与限制：支持的资产、操作与范围。
