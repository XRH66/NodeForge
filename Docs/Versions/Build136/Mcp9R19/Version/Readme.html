此版为PC2源码预期资料：新原生目录/操作在PC3同窗取得并准确核对，随后才执行新生成/Verify。编译和离线资料不是产品业务、安装、画面、打包或包后运行通过。Manifest.publicationStatus是当前准确发布层，最终证据由本轮终审更新；根Build2/RC1不升级。
