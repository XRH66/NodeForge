# NodeForge v0.2.0

本版增加引擎级共享安装和 AI 一次接入。官方 UE 5.3.2 / Windows 64 位；桥 0.4.0、MCP SDK 2.3.0、20 个工具。节点目录仍为 experimental，沿用 71 材质类、327 蓝图签名，不扩大节点资格。

- 同一普通 ZIP 支持引擎 Marketplace、引擎直接 Plugins 和高级工程 Plugins。
- AI 补装到同一位置，使用包内固定 Python 3.12.4 环境，客户端配置一次。
- 正常打开工程自动建立独立会话；唯一目标自动连接，多个候选需选择，零工程可读文档。
- 关闭重开识别新会话并拒绝旧句柄；程序目录不写运行状态，保留用户凭据与资产保护。

必要验证包括最终核心真实首次确认/重开、工程级保留、双工程、正常启动 MCP、材质和蓝图保存及新进程独立回读。第二台干净机器、所有客户端、其他 UE/系统以及未变节点整批不属于这次新增验证。
