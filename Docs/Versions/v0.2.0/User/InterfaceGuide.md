# 界面与按钮

从 **窗口（Window）→ NodeForge** 打开面板。插件处理操作时，一些按钮会暂时不可用；操作结束后会恢复。某些按钮还需要读取结果、导出来源或上次成功输入。

## 输入与生成

| 按钮 | 作用 | 操作后做什么 |
| --- | --- | --- |
| 恢复上次输入 | 恢复上一份可恢复的 JSON 输入 | 检查恢复的内容，再重新检查输入 |
| 粘贴剪贴板 | 用剪贴板中的完整文本替换输入框 | 确认内容完整，再检查输入 |
| 载入 JSON 文件 | 选择文件并替换当前输入 | 检查目标名称与参数；取消选择不会生成资产 |
| 检查输入 | 检查当前 JSON、节点、连线和目标是否符合规则 | 有错误时打开报告，修改后重新检查 |
| 准备新副本 | 为当前输入填入新的资产名称和 requestId | 确认新名称，检查输入，再生成 |
| 生成新资产 | 根据当前输入创建、编译并保存资产 | 查看结果，定位或打开生成的资产 |

`requestId` 是一次生成请求的编号，由“准备新副本”自动填写。已有资产名称或已使用的请求编号会被拒绝。

载入、准备和检查都不会保存新资产。“准备新副本”也不会提前占用名称，真正生成时还会检查是否有冲突。

**恢复上次输入**只恢复输入框内容，不会撤销已经生成的资产。在输入框使用 Ctrl+V 时，会按光标或选区插入；**粘贴剪贴板**按钮则替换整份输入。

## 节点规则与资源查看

| 按钮 | 作用 | 使用条件 |
| --- | --- | --- |
| 查询材质规则 | 查找材质节点、参数和引脚规则 | 查询框输入关键词；留空查询全部 |
| 查询蓝图规则 | 查找蓝图节点和调用规则 | 查询框输入关键词；留空查询全部 |
| 导出全部节点规则 | 读取本版完整节点目录 | 无需选择资产 |
| 读取选中材质 / 函数 | 读取材质参数或材质函数签名 | 只选一个已保存、无未保存改动且允许读取的资源 |
| 复制读取内容 | 复制最近一次完整读取结果 | 已成功读取规则、资源信息或图数据 |

规则查询最多接受 256 个字符和 8 个空格分隔的关键词；匹配任意一个关键词即可。规则查询框不会改变构图输入。

读取资源不支持材质实例、函数实例、材质层或多选。读取失败会清空旧的复制内容，避免把上一次的结果误当成本次结果。

## 已有构图与新副本

| 按钮 | 作用 | 使用条件 |
| --- | --- | --- |
| 只读导出选中构图 | 把选中的支持图导出为 JSON，并载入输入框 | 只选一个已保存、无未保存改动的支持图 |
| 预览新副本差异 | 比较当前输入与导出的原图 | 当前输入仍保留有效的导出来源；原资产未改变 |
| 按上次成功输入重排新副本 | 自动排列上次成功输入中的节点，并生成另一份资产 | 有上次成功生成时保存的完整输入 |

导出与预览不会修改原资产。重排按钮会生成新资产，使用的是上次成功输入；你后来在 UE 中对资产所做的编辑不会包含在内。

完整操作顺序见 [编辑新副本](CopyPreview.md)。

## 最近结果与报告

| 按钮 | 作用 |
| --- | --- |
| 定位资产 | 在内容浏览器中定位本次结果中的资产 |
| 打开资产 | 用 UE 资产编辑器打开本次结果中的资产 |
| 打开完整报告 | 查看错误原因、处理步骤和完整结果 |
| 复制完整报告 | 复制完整报告，便于排查问题或交给 AI |

修改输入后，上一次的检查与结果会过期。定位和打开资产按钮只针对仍有效的结果；报告保留原操作信息。

`waitingPersistence` 表示资产已经保存，尚未在重新启动编辑器后检查。需要确认重开后的内容时，可以让有本机操作权限的 AI 按 [结果检查说明](../Ai/ResultsAndRecovery.md) 执行。面板没有单独的 Verify 按钮。

## 其他提示

输入框旁的文件名和字节数可以帮助确认载入的是哪份文件。两个折叠区域分别放置规则与资源操作，以及图导出与副本操作。

关闭面板不会取消已经提交的任务。遇到未完成或未知结果时，先保留输入与报告，按 [常见问题](Troubleshooting.md) 处理。
