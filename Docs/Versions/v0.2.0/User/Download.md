# 下载 NodeForge

**v0.2.0 · 官方 UE 5.3.2 · Windows 64 位。** 普通插件独立使用；AI 接入包是可选补充，没有第二份核心 DLL。

| 使用方式 | 下载 | 下一步 |
| --- | --- | --- |
| UE 面板操作 | [NodeForge-0.2.0-UE5.3.2-Windows.zip](https://github.com/XRH66/NodeForge/releases/download/v0.2.0/NodeForge-0.2.0-UE5.3.2-Windows.zip) | [复制到引擎目录](PluginInstallation.md) |
| AI 操作插件 | [NodeForge-AI-0.2.0-Windows.zip](https://github.com/XRH66/NodeForge/releases/download/v0.2.0/NodeForge-AI-0.2.0-Windows.zip) | [一次接入](AiInstallation.md) |

先保存并关闭使用插件的编辑器。普通用户将 ZIP 中的 NodeForge 文件夹复制到引擎 `Engine/Plugins/Marketplace`，然后在工程启用。AI 包解压到临时目录，按指南指定引擎与客户端；环境补装到同一插件位置。

准确大小和 SHA256 以同页 [ReleaseManifest.json](https://github.com/XRH66/NodeForge/releases/download/v0.2.0/ReleaseManifest.json) 与 [Checksums.sha256](https://github.com/XRH66/NodeForge/releases/download/v0.2.0/Checksums.sha256) 为准。GitHub 的 Source code 附件是源码，不能代替插件 ZIP。

仓库为私有，下载需登录有访问权的账号。404 时先检查账号权限，再从 [Release 附件列表](https://github.com/XRH66/NodeForge/releases/tag/v0.2.0) 下载；网站权限与 GitHub 权限分别管理。
