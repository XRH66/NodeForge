# 界面与按钮

从 **窗口 → NodeForge** 打开原生面板。可以停靠、浮动或调整宽度；窄面板会换行，文字不整体缩放。输入可纵向调高，长内容使用渐隐滚动条。未满足前提的按钮会禁用，处理中的写操作不能重复提交。

## 输入与生成

| 按钮 | 作用与前提 |
| --- | --- |
| 粘贴 | 用剪贴板完整文本替换输入。输入框 Ctrl+V 则按光标或选区插入 |
| 载入 | 打开小窗口；文件夹图标选择 JSON，右侧“载入案例”读取包内合法例子。取消不改变资产 |
| 恢复输入 | 恢复前一份可恢复的输入，包括空输入；不撤销资产或恢复旧预检资格 |
| 新建副本 | 为当前草稿准备新 requestId 和目标名称；只准备，不保存、不预留 |
| 检查 | 检查 JSON、节点、连接、来源和目标；不生成资产 |
| 生成 | 直接执行原检查和生成，编译并保存新资产；没有额外确认或成功提示窗 |

空初态为零字节、无结果，依赖输入或历史的操作不可用。主动载入案例后才是待生成。已有资产或已使用的请求编号会拒绝；原资产不覆盖。

## 构图与副本

| 按钮 | 作用与前提 |
| --- | --- |
| 导出构图 | 从主内容浏览器唯一选中的支持资产导出完整图，并按真实来源载入草稿；必须已保存且来源可核 |
| 查看差异 | 当前草稿与原导出图比较；来源仍有效、原文件未改时可用。结果窗口只读 |
| 复用上次构图 | 按上次成功保存的完整输入重排节点并生成另一件新资产；不使用后来任意编辑的草稿 |

导出默认使用 v2；AI/CLI 可显式选择 v3。准备、预览和重排保持草稿格式。来源为 `sourceMemoryUnproven` 时先按[问题处理](Troubleshooting.md)核原保存状态，不自动重载或保存原资产。

## 规则与资源

| 按钮 | 作用与前提 |
| --- | --- |
| 材质规则 / 蓝图规则 | 查询框输入关键词；留空返回该类全部规则 |
| 导出规则 | 读取本版完整目录，不需要选择资产 |
| 读取资源 | 精确检查主内容浏览器中唯一选中的支持材质或材质函数；已保存且允许读取 |
| 复制内容 | 复制最近一次成功读取的完整内容；失败清空旧内容，避免混用 |

查询框最多 256 字符、8 个空格分隔关键词，匹配任意关键词，不改变构图输入。资源有界搜索通过 AI 的 `resources.query`；面板的读取按钮负责精确检查。查询结果、允许读取、可引用与整图可导出是不同条件。

## 结果与报告

输入下方显示当前来源、字节数或真实执行提示。拒绝发生在报告生成前也会显示原因，不伪造成功。

| 按钮 | 作用与前提 |
| --- | --- |
| 打开生成资产 / 定位生成资产 | 打开或定位当前有效结果中的准确资产，没有结果时隐藏或禁用 |
| 报告 | 读取原完整报告，展示错误与处理结果 |
| 复制报告 | 在报告窗口复制该报告完整原文，文件变化时拒绝复制旧内容 |

输入改变使旧结果失效。`waitingPersistence` 是保存后的待独立核验状态；面板没有单独 Verify 按钮。新进程核验、运行、画面和打包各自检查，见[结果说明](../Ai/ResultsAndRecovery.md)。未知结果先查原调用，不换身份重发。

## 顶部与设置

**使用手册**直接打开官网用户手册；齿轮打开设置。Tab 移动焦点，Enter 激活，Escape 关闭次级窗口，不提交未应用的设置。

| 页面或动作 | 作用与前提 |
| --- | --- |
| 常规 | 默认创建目录用于案例和新目标准备；已有 JSON 的明确目标保持。只能使用已允许的测试子目录 |
| AI 客户端 | 选择 DeepSeek、Codex、Claude 或自定义项；名称、图标与状态对应当前项 |
| 添加客户端 / 导入信息 | 添加名称、说明及可选图标，或导入实际支持的信息；不填写虚构 API Key |
| 浏览图标 | PNG/JPEG/WebP，最多 200KB，经过真实解码后保存；错误行内显示 |
| MCP | 查看真实安装状态与配置，复制配置、打开接入流程、启用或停止本工程服务 |
| 关于 | NodeForge 品牌、准确产品版本、功能简介、官网与 GitHub 链接；只读，不应用其它页草稿 |
| 取消 / 关闭 | 丢弃未应用草稿，保留已应用配置 |
| 应用 | 校验并持久化真实配置，重开恢复；错误时保留可修正草稿 |

AI 下拉中的选择不等于连接。Codex 状态来自真实握手；断开只关闭本工程该客户端的匹配连接，保留其它客户端和工程。Claude、DeepSeek 和自定义项本版显示“未检测”，保留选择、图标、配置和入口框架；没有专有在线检测或自动重连。服务已启用也不等于客户端在线。

关闭面板不取消已提交任务，工程切换和重开后按实际会话读取；各工程的设置和报告隔离。详见[连接 AI](AiInstallation.md)、[编辑新副本](CopyPreview.md)。
