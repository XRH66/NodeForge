# NodeForge 能做什么

NodeForge 将 JSON 中描述的节点、参数和连线生成到 UE 资产中。生成后，你可以继续用 UE 自带的材质编辑器或蓝图编辑器修改它们。

## 支持的资产

| 资产 | 可以描述的内容 |
| --- | --- |
| 普通材质 | 颜色与数值参数、数学运算、插值、纹理、UV、空间与法线运算，以及支持的材质函数调用 |
| Actor 蓝图 | 单个 EventGraph 中的事件、函数调用、成员变量、分支、Sequence 和支持的 Switch 节点 |
| 普通材质实例 | 使用已保存的父材质，设置插件支持的参数覆写 |

精确的节点、引脚和配置见 [材质节点索引](../Reference/MaterialNodeIndex.md) 与 [蓝图节点索引](../Reference/BlueprintNodeIndex.md)。材质实例需要读取真实父材质参数，使用方法见 [材质实例](../Reference/MaterialInstance.md)。

## 常用操作

- **生成：** 载入完整 JSON，检查，再生成、编译和保存。
- **查询规则：** 查看可用节点及其参数，或导出规则交给 AI。
- **读取资源：** 读取支持的已保存材质参数、函数签名和资源信息。
- **编辑新副本：** 导出支持的材质或 Actor 蓝图，修改 JSON、查看差异，然后生成。
- **连接 AI：** 让客户端读取文档、查询节点和资源、准备输入并提交生成任务。

## 使用前了解这几项限制

本版只在 `Content/NodeForgeTests` 下创建新资产，不会覆盖已有资产。蓝图限普通 Actor 的单个 EventGraph；数组、循环、多图、额外组件、自定义父类及任意函数调用不在当前范围。

已有图必须能够完整导出。遇到不支持的节点或属性，插件会提示原因，不会静默省略它们。材质实例没有专用的 MCP 操作，也不能作为整图导出。

节点目录中标为 `experimental` 的条目仍处于实验支持阶段。生成后请在自己的工程中检查材质效果或蓝图行为；保存成功只表示资产已写入磁盘。
