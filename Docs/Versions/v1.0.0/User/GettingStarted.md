# 生成第一个材质

先按 [安装插件](PluginInstallation.md) 启用 NodeForge。普通插件无需 AI 或 Python。

## 1. 打开面板

在 UE 中选择 **窗口 → NodeForge**。首次使用确认自动识别的工程、引擎和插件位置；之后正常打开工程即可使用。

初次进入输入为空、零字节，没有生成结果。这是正常状态。

## 2. 载入案例

点击 **载入**，再点击窗口右下方的小字 **载入案例**。插件会读取包内真实示例，用当前目录和设置中的默认目录准备新目标，不会生成资产。

也可点击文件夹图标选择自己的 JSON；包内例子位于 `NodeForge/Examples/FirstMaterial.json`。该例子描述可调颜色和粗糙度的材质。

## 3. 检查并生成

1. 点击 **检查**，根据输入下方的提示确认是否通过。需要详细原因时打开 **报告**。
2. 点击 **生成**，直接检查、编译并保存新资产，没有额外确认或成功弹窗。
3. 生成结束后点击 **打开生成资产** 或 **定位生成资产**。

生成结果仍可在 UE 材质编辑器中编辑。`waitingPersistence` 表示已保存，尚未由新编辑器进程独立核验；它不是保存失败，也不包含画面或运行检查。

## 4. 再做一份

已有目标或已使用的请求编号会被拒绝。点击 **新建副本** 准备新名称，再检查并生成；准备本身不会创建资产或提前占用名称。**恢复输入**只恢复前一份可恢复的文本，不撤销生成。

需要 AI 编写 JSON 时，先用 **导出规则 → 复制内容** 提供本版规则；也可 [连接 AI](AiInstallation.md) 直接调用插件。

错误或结果不明确时打开原 **报告**，保留输入并查清原任务；不要换名重复提交未知生成。
