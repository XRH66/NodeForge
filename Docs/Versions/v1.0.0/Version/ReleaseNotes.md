# NodeForge v1.0.0

本版将 NodeForge 的紧凑界面接入原生 Slate，并完成实际按钮、设置和 Codex 接入闭环。支持官方 UE 5.3.2 / Windows 64 位；桥 0.4.1、MCP SDK 2.3.0、ABI1、20 个工具。71 类材质节点、327 条蓝图签名/8 类仍为 experimental，没有新增节点范围。

- 单列输入和紧凑结果栏，按钮随宽度换行，支持停靠、浮动、输入拖高与渐隐滚动。
- 恢复载入/案例/粘贴/恢复、检查生成、导出副本差异、规则资源和准确报告；生成无额外确认。
- 设置支持草稿、应用、取消和重开，客户端图标有界校验，独立关于页和真实官网入口。
- Codex 按真实握手显示在线，定向断开保留其它会话；选择与连接分离。
- Claude/DeepSeek 只交付配置与入口框架，明确未检测，专有检测延期。
- 干净首次为空输入、零字节、无结果；保留真实用户设置及原来源/目标保护。

普通插件复制到引擎插件目录即可使用；AI 可选补装到同一位置，配置一次后正常打开工程连接。引擎级与高级工程级不重复安装同名插件。

本版复用未变节点、JSON v2/v3、实例和已有有限运行资格。真实 UI、代表材质/蓝图保存及新进程独立核验已执行；并不扩展为全组合、所有客户端、第二台机器或其它 UE 版本的验证。
