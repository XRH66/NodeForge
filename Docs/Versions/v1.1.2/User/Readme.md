# 用户手册

第一次使用，按 **安装 → 生成示例 → 查看结果** 的顺序即可。想让 AI 操作插件时，再安装 AI 接入包。

## 了解与安装

- [功能介绍](Overview.md)：先了解插件能做什么。
- [下载插件与 AI 包](Download.md)：选择安装包并确认支持环境。
- [选择安装方式](Installation.md) → [安装插件](PluginInstallation.md)。

## 上手与日常操作

- [先试用附带案例](GettingStarted.md)：从附带示例完成第一次创建。
- [界面与按钮](InterfaceGuide.md) → [手动操作](ManualWorkflows.md)。
- [修改已有图并生成新副本](CopyPreview.md)。
- [查找可用节点](NodeCoverage.md)。

## 自己写或让 AI 写 JSON

想让 AI 按规则写出蓝图或材质 JSON 时，先下载对应的一份规则，再按步骤生成；普通聊天工具即可，不必安装 AI 接入包。

- [材质编写规则](../Reference/MaterialRules.md)：JSON 格式、材质设置、全部材质节点与限制。
- [蓝图编写规则](../Reference/BlueprintRules.md)：JSON 格式、变量、全部蓝图节点与引脚。
- [让 AI 写出自己的 JSON](ManualWorkflows.md#让-ai-写出自己的-json)：包含可复制的提示词。

## AI 与问题处理

- 需要 AI 直接操作插件时，先[连接 AI](AiInstallation.md)，再看[使用流程](AiWorkflows.md)。
- 遇到错误时查看[问题处理](Troubleshooting.md)。

本手册适用于 NodeForge v1.1.2、Windows 64 位、官方 UE 5.3.2。详细的资产类型与限制见 [支持范围](../Reference/FeatureMap.md)。
