# 手动操作

安装后，从 **窗口（Window）→ NodeForge** 打开面板。第一次使用建议先完成 [先试用附带案例](GettingStarted.md)。以下操作均在这个面板中进行。

## 从 JSON 生成资产

1. 点击 **载入**，选择一份完整输入；也可以复制 JSON 后点击 **粘贴**。
2. 检查目标资产名称和位置。本版生成位置在 `Content/NodeForgeTests` 下。
3. 点击 **检查**。有错误时点击 **报告**，修改对应字段后重新检查。
4. 点击 **生成**。
5. 查看结果，再点击 **定位生成资产** 或 **打开生成资产**。

再次生成同一份输入时，先点击 **新建副本** 分配新名称。已有资产不会被覆盖。完整输入示例见 [JSON 示例](../Reference/Examples.md)。

## 让 AI 写出自己的 JSON

不需要安装 AI 接入包，也不需要配置 MCP。普通的生成式 AI 聊天工具就可以完成；关键是给它一份对应的规则文档。

1. 下载要用的那一份规则：[材质编写规则](../Reference/MaterialRules.md) 或 [蓝图编写规则](../Reference/BlueprintRules.md)。规则里已经写清格式、限制、可用节点和引脚信息，不需要再让 AI 去插件里查询。
2. 明确告诉 AI 你要什么：目标是材质还是 Actor 蓝图，要什么效果或逻辑，需要哪些输入参数，以及工程里已经存在的资源路径（例如贴图）。
3. 把规则文档和需求一起发给 AI，要求它按规则输出完整的 JSON。可以附上下面的提示词。
4. 复制 AI 返回的 JSON，在面板点击 **粘贴**；或先保存成 `.json` 文件，再点击 **载入**。
5. 点击 **检查**。字段、节点或连线不符合规则时，按 **报告** 的提示修改，也可以把报告内容贴回给 AI 让它改。
6. 检查通过后点击 **生成**，再在 UE 中打开资产，运行蓝图或查看材质效果。

一段可以直接复制的提示词：

~~~text
请按我附上的 NodeForge 规则文档，写出一份可以直接提交的完整 JSON。

需求：<在这里描述你要的材质效果或蓝图逻辑>
已有资源：<贴图或材质函数等真实资源的完整路径；没有就写“无”>

要求：
- 只使用规则文档中列出的节点、字段和取值；
- 输出一个完整的 JSON 代码块，不要省略任何字段，不要用省略号代替内容；
- requestId 和目标资产路径使用未占用的值；
- 如果缺少必要信息，先列出问题等我的回答，不要猜测。
~~~

只让 AI 写 JSON 时，到这里就够了。面板里的 **导出规则** 和 **读取资源** 仍可作为辅助：前者导出的是本版内置规则；后者用于读取支持的已保存材质参数与材质函数签名，面板只接受普通 `UMaterial` 与 `UMaterialFunction`，不读取贴图资源。贴图的完整对象路径可以在内容浏览器中复制后提供给 AI。它们都不是生成前必须完成的步骤。

要让 AI 查询规则、读取资源并直接提交任务，需要安装 AI 接入包，见 [连接 AI](AiInstallation.md)。

## 读取材质参数或函数签名

在内容浏览器中只选择一个已保存、没有未保存改动的普通材质或 `MaterialFunction`，点击 **读取资源**。成功后，点击 **复制内容** 获取参数或引脚信息。规则文档里列出的是节点目录；工程里某个材质函数的实际路径、摘要和端口，需要这样读取后使用。

资源必须位于当前允许读取的目录。此操作只接受已保存的普通材质或材质函数，不读取贴图；贴图路径请在内容浏览器中复制。不接受材质实例、函数实例、材质层或多选。若出现 `sourceMemoryUnproven`，请按 [常见问题](Troubleshooting.md) 处理；插件不会为了读取而自动重载或保存原资产。

## 修改已有图，生成新副本

1. 在内容浏览器中选择一个支持的已保存材质或 Actor 蓝图。
2. 点击 **导出构图**，将图载入输入框。
3. 修改需要改变的参数，点击 **新建副本**。
4. 点击 **查看差异**，确认改动内容。
5. 检查并生成。

原资产保留。操作细节和支持范围见 [编辑新副本](CopyPreview.md)。

## 自动重排上次生成的节点

点击 **复用上次构图**。插件会使用上次成功生成时保存的 JSON，去掉显式节点坐标，重新排列并生成一份新资产。

它使用上次成功输入，不会读取你后来在 UE 中手改的资产，也不会使用另一份尚未生成的当前草稿。布局尺寸为估算值，生成后可以继续手动调整。

## 创建普通材质实例

先准备已保存的普通 Surface 父材质，读取它的实际参数，再按 [材质实例说明](../Reference/MaterialInstance.md) 填写输入、检查和生成。示例中的资源路径需要换成自己工程里的真实资源，参数名必须与父材质一致。

## 操作失败时

点击 **报告**，先看本次是否已经保存资产。如果结果仍为 `pending` 或 `unknown`，保留输入和报告，先查清原操作，不要连续点击生成。
