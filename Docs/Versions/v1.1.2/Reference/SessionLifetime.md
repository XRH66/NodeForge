# Windows 登录与连接权限

NodeForge 的工程会话目录由当前 Windows 用户持有。每次运行的私有会话、凭据和管道只供当前登录使用，旧会话不会在重新登录后继续使用。

升级后，插件会在正常启动时识别并迁移符合旧版格式的会话父目录。迁移保留旧私有目录、凭据和报告，不递归放开权限。未知权限或异常路径仍会拒绝。

如果出现 `controlSessionContainerRejected`，保留完整错误提示和 Windows 错误码。不要删除旧凭据、授予 Everyone 权限或复制另一工程的会话目录。

需要把工程交给另一个 AI 对话时，按[交接连接](SessionHandoff.md)正常释放当前连接。
