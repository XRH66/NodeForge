# 更新日志

按发布时间记录 NodeForge 正式版本的主要变化。推荐使用当前版本；历史记录供查阅。

[下载当前版本](../User/Download.md) · [升级说明](CompatibilityAndMigration.md)

## v1.1.2 · 当前版本

2026-10-20

- 自动回收已完成调用，AI 连续操作无需计数或手动清理，原调用与报告继续保留。
- 插件手册与关于页统一使用 nodeforge.cn，更新公开下载和升级说明。

## v1.1.1

2026-10-16

- 支持主动回收已完成的调用记录，让 AI 批量操作可以继续进行，原调用和报告仍可查看。
- 修复大型工具定义文件的读取问题，改进连续调用的稳定性。

## v1.1.0

2026-10-16

- 新增清漆、各向异性、切线输入和 IOR 折射支持。
- AI 可主动释放连接，方便另一对话接手，无需关闭 UE。
- 改进复杂材质布局、工程识别和连接稳定性。

## v1.0.0

2026-10-14

- 推出原生 UE 面板，支持停靠、浮动和可调输入区域。
- 在面板中完成构图、资源读取、副本生成、差异预览和报告查看。
- 新增工程独立设置、客户端管理和官网手册入口。

## v0.2.0

2026-10-14

- 支持引擎级安装，多个工程可以共用插件。
- AI 接入只需配置一次，之后正常打开工程即可连接。
- 改进工程与会话隔离，多个工程运行时可明确选择目标。

## v0.1.0

2026-10-13

- 首个可用版本：通过 JSON 创建可编辑的材质与 Actor 蓝图。
- 支持规则查询、资源读取、图导出和新副本生成。
- 提供可选 AI 接入包，通过 MCP 调用插件。

当前支持 Windows 64 位和官方 Unreal Engine 5.3.2。具体支持范围与限制请查看[兼容与升级](CompatibilityAndMigration.md)及[已知限制](KnownIssues.md)。
