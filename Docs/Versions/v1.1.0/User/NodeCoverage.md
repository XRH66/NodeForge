# 查找可用节点

本版节点目录包含 **71 种材质节点和 327 个蓝图调用签名**。同一个 UE 节点可能有不同的参数或调用形式，编写 JSON 时应以目录中列出的具体形式为准。

## 在插件中查询

1. 打开 **节点规则与资源查看**。
2. 在规则查询框输入节点名或关键词。
3. 点击 **材质规则** 或 **蓝图规则**。
4. 查看完整报告，或点击 **复制内容**，把规则交给 AI。

查询框留空可以读取该类的全部规则。多个关键词用空格分隔，匹配任意一个关键词即可；最多输入 256 个字符、8 个关键词。

要一次导出全部规则，点击 **导出规则**。也可以直接查阅 [材质节点索引](../Reference/MaterialNodeIndex.md) 和 [蓝图节点索引](../Reference/BlueprintNodeIndex.md)。

## 选节点时注意什么

| 任务 | 要检查的内容 |
| --- | --- |
| 数学、比较、字符串、向量或旋转运算 | 函数的完整名称、输入与输出类型；不要混接 `float` 和 `double` 引脚 |
| 材质数学、颜色和插值 | 输入名称、输出编号，以及节点是否连接到最终材质输出 |
| 纹理或材质函数 | 真实资源路径、资源类型、函数引脚及当前资源是否可以读取 |
| 变量、分支或 Switch | 本版允许的变量类型、节点配置和连线规则 |

目录没有列出的节点或配置目前不能使用。不要直接照搬其他 UE 版本截图中的引脚名称。

## experimental 是什么意思

它表示这个节点可以按目录规则使用，但所有参数组合和实际效果还没有逐一验证。输入检查通过后仍需生成、编译，并在自己的工程中查看运行或渲染结果。

数组、循环、额外组件、多图和自定义父类目前未支持。完整说明见 [已知限制](../Version/KnownIssues.md)。
