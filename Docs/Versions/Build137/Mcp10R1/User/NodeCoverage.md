# 节点选择与支持层次

普通材质与 Actor 蓝图沿原来的 JSON 载入、检查、生成按钮使用。本版精确目录有 71 材质类 / 327 蓝图签名；完整名单看 [材质节点](../Reference/MaterialNodeIndex.md)、[蓝图节点](../Reference/BlueprintNodeIndex.md)。

## 怎样选择

| 要做什么 | 选择和边界 |
| --- | --- |
| 数值、布尔、字符串/名称、向量和旋转计算 | 蓝图两个受控原生库的普通纯函数，连接到实际使用结果的节点；float/double 按端口类型接线 |
| 颜色、数值、插值和数学变换 | 普通 Surface 材质的原生表达式；按输入名和输出数字索引接线，所有表达式到达材质输出 |
| 纹理、材质函数、成员变量、分支、多路选择和 Actor/root | 读取对应已有特殊类别限制、真实资源/配置及签名，不能只写类名 |
| 循环、数组、额外对象/组件、多图、新父类 | 当前未提供这些共同能力，不因某个相似节点可发现而开放 |

## “支持”是什么意思

发现仅表示身份存在；experimental 表示已通过受控原生实例/端口资格且允许按规则生成。实际组合的编译保存和独立重开要看对应报告，未测组合、运行和材质画面不会因为名单变长自动通过。AI 可以读取本版节点页与 [调用配方](../Ai/NodeBulk.md)，你不必阅读内部锁或协议代码来选节点。

目录是本版唯一支持依据；不要照搬其它 UE 版本截图的引脚名或把新节点塞进旧摘要输入。生成时拒绝不存在/不支持配置，保留原资产；出现结果未知先查询原报告，避免重复生成。
